# Security policy

This repository holds only the catalog. A vulnerability in a plugin belongs to that plugin's repository: report it
there, privately, as its `SECURITY.md` describes (for
[cache-weather-and-pause-resume](https://github.com/DarthSonic/cache-weather-and-pause-resume/security/advisories/new)).

A problem with the catalog itself, say an entry that points at a repository other than the plugin's own, is reported
here, privately as well: do not open a public issue, but use
[Report a vulnerability](https://github.com/DarthSonic/claude-plugins/security/advisories/new) (the **Security** tab,
then **Report a vulnerability**).

The catalog is maintained by one person in their spare time. You will get an answer.

A problem in Claude Code itself belongs to Anthropic, not to this repository.
